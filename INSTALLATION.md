## 🚀 Démarrage

### Installation
```bash
npm install
```

Ou si react-router-dom n'est pas installé:
```bash
npm install react-router-dom@6.20.0
```

### Développement
```bash
npm run dev
```
Le site sera accessible à `http://localhost:3000`

### Build Production
```bash
npm run build
```

### Preview
```bash
npm run preview
```
