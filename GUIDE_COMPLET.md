## 🛠️ Installation & Lancement

```bash
cd c:\Users\UNCHK\Desktop\safebuild-qhse-consultancy

```

### 2️⃣ Lancer le serveur de développement

Accédez à: **http://localhost:3000**

### 3️⃣ Build pour production
```bash

```
